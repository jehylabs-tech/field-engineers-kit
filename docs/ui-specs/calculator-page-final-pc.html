계산 근거 (Applied Formula — AISC 360)

단순지지보의 등분포 하중에 대한 최대 처짐량은 δmax = 5wL⁴ / 384EI 로 산출되며, 사용성 한계상태는 L/360 기준을 적용합니다.

허용 처짐 기준은 왜 L/360인가요?
바닥 마감재 손상을 방지하기 위한 일반적인 사용성 한계이며, 부재 용도에 따라 L/240~L/600까지 적용될 수 있습니다.
단면 2차 모멘트(I) 값은 어디서 확인하나요?
강재 단면 규격표(KS/AISC Shape DB)에서 확인 가능하며, SpecSelect 검색으로 규격명을 입력하면 자동 반영됩니다.
